# 万博プロジェクト　岡本

## expo_fix_msgs
expo_msgs の緯度経度バージョンの独自メッセージ群です。

## expo_crowd_msgs
混雑度専用の独自メッセージ群です。

## expo_fix2xyz
fixトピックから万博プロジェクト用の規定デカルト座標系へ変換するパッケージです。  
原点の緯度経度を指定して、fixトピックをxyzに変換します。

## expo_bash_trigger
任意のString型トピックを受け取った際に、任意のスクリプトファイルを実行するノードです。  
ブラウザ画面からのwizurgの起動などに使用する予定です。

## expo_safety_manage
エラー検出等の専用パッケージです。  
・UTMのデータを受けて、ロボットの速度司令をON,OFFする「速度司令ノード」
・各種センサーのトピックを監視して、通信不可のものがあればエラーを出す「通信監視ノード」
を含みます。
